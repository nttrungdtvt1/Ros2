7. WHAT NEEDS TO CHANGE FOR OBSTACLE AVOIDANCE
================================================================================

The Nav2 costmap layers are ALREADY configured for obstacle avoidance:

LOCAL COSTMAP (nav2_params.yaml):
  - voxel_layer: reads /scan (LaserScan), marking + clearing, max_range 2.5m
  - inflation_layer: cost_scaling 3.0, radius 0.55m

GLOBAL COSTMAP (nav2_params.yaml):
  - obstacle_layer: reads /scan (LaserScan), marking + clearing, max_range 2.5m
  - static_layer: loads map
  - inflation_layer: cost_scaling 3.0, radius 0.55m

BEHAVIOR SERVER:
  - spin, backup, drive_on_heading, wait, assisted_teleop
  → These are recovery behaviors when robot gets stuck

DWBC CONTROLLER:
  - Critics: RotateToGoal, Oscillation, BaseObstacle, GoalAlign, PathAlign, PathDist, GoalDist
  - BaseObstacle.scale: 0.02 (LOW - should increase for better avoidance)
  → BaseObstacle.scale should be increased to ~1.0 for real-world obstacle avoidance

PLANNER:
  - NavfnPlanner (Dijkstra) - works but Nav2 also supports Smac2D/SmacHybrid-A* for better planning

TO IMPROVE OBSTACLE AVOIDANCE:
  1. Increase BaseObstacle.scale in nav2_params.yaml from 0.02 to 1.0
  2. Ensure /scan topic is publishing (LiDAR must be running)
  3. Test with real robot - costmap resolution and ranges may need tuning
  4. Consider adding range_sensor_layer for better LiDAR integration

8. REAL ROBOT LAUNCH SEQUENCE
================================================================================

To run the full system on real robot, the launch order should be:

Terminal 1: Robot hardware + sensors
  ros2 launch articubot_one launch_robot.launch.py

Terminal 2: LiDAR (if not integrated)
  ros2 launch ldlidar ldlidar.launch.py
  OR
  ros2 launch articubot_one rplidar.launch.py

Terminal 3: SLAM (for mapping first time)
  ros2 launch articubot_one online_async_launch.py

Terminal 4: Save map after mapping
  ros2 run nav2_map_server map_saver_cli -f my_room_map

--- After map exists ---

Terminal 3: Localization (instead of SLAM)
  ros2 launch articubot_one localization_launch.py map:=<path>/my_room_map.yaml

Terminal 4: Navigation
  ros2 launch articubot_one navigation_launch.py use_sim_time:=false

Terminal 5: Waypoint mission (NEW)
  ros2 launch robot_mission mission.launch.py
